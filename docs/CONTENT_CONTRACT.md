## 项目 YAML 约定

项目头部按发布与路由、名称与简介、类别与时间、方向与技术组织。正常项目继承集合默认值 `layout: project`、`overview_in_facts: true`、`importance: 0`；保留显式例外覆盖，不重复填写默认值或 `summary: false`。

| 字段                                     | 用途                                                       |
| ---------------------------------------- | ---------------------------------------------------------- |
| `published`                              | 显式 `true` 才发布                                         |
| `lang` / `translation_key` / `permalink` | 语言、稳定配对键与公开地址；不随标题改名                   |
| `title` / `description`                  | 名称与共用简介；卡片和详情概述使用同一值                   |
| `category`                               | `work`／`fun`，仅源分类                                    |
| `project_type`                           | `internship`／`research`／`engineering`／`personal`        |
| `period`                                 | 明确的 `YYYY.MM—YYYY.MM` 或 `YYYY.MM—至今`；英文用 present |
| `sort_date`                              | 完成项目填写带引号的 `YYYY-MM`，与结束月份一致             |
| `status`                                 | 进行中填写 `ongoing` 并省略 `sort_date`                    |
| `organization`                           | 可选合作单位，缺少时省略                                   |
| `topics` / `tech_stack`                  | 用户校对的方向／核心技术数组，保留原值、顺序和粒度         |

`importance` 仅作同组备用顺序，不表示精选。进行中优先；其余按完成月份倒序；无日期项目最后。相邻导航沿用同一全局顺序。

保留真实资源与图片扩展字段：`paper`、`github`、`website`、`data_url`、`publication_key`、`related_posts`、`img` 及宽高／alt／caption。`project_date` 仅表示明确单日日期；不使用 Jekyll 自动集合日期。没有资料时省略字段，不添加占位资源。旧职责和独立 highlights 展示已经移除；职责及完成事实保留正文。
