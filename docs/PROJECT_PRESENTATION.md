# 内容与视觉约定

保持已确认的 Blue Topaz／Topaz Nord 风格，样式清理不重写个人内容。项目范围和字段见 [内容约定](CONTENT_CONTRACT.md)。共享字体与尺度在 `assets/css/typography.css`，框架在 `about.css`，栏目和详情在 `site.css`。

## 字体、颜色与层级

- 使用本地 Academic Sans，中英文保持同一字体。字形按 Unicode 静态分片，不恢复完整字库预加载，维护入口见 [字体说明](../assets/fonts/README.md)。中文正文起始对齐；英文简介、摘要、正文及 prose 列表两端对齐，末行起始对齐并允许自动断词；标题、导航、侧栏和结构化 metadata 不强制两端对齐。
- 保留 Nord 的冷灰背景、蓝色强调、明暗变量。H1 中性色，正文各级标题使用既有层级色；不要给每个术语加醒目彩色标签。
- 正文 16px／1.8 行高；H1／H2／H3／H4 使用 28／22／18／16px，窄屏按共享变量收缩标题，正文仍为 16px。标题、列表和项目资料不另建独立尺度。
- About 内容右边界与导航主题工具右侧对齐。项目和博客列表／正文最大宽度为 760px，文档图片声明真实尺寸，不设大面积空封面。

## 导航与共用资料

English 为 About／Projects／Blog／Awards，中文为关于我／项目／博客／获奖。Blog 保持单数。语言和主题图标为同风格 18px SVG、1.6px 描边、32px 控件，在同一工具组垂直居中，保留 hover／focus、目标语言 tooltip、hreflang 和对应页链接。

每页共用 about 的本地化 profile，桌面保留文字标签，手机紧凑显示。只显示 email、LinkedIn、ORCID。邮箱除跳转外在简介博士机会句中保留可复制地址。首页简介无标题，随后依次为 🔥 动态、📝 学术论文、📖 教育背景；空动态不显示占位文案。

教育每学位一段普通文字，学位前置、时间后置；无表格、卡片、分栏、内部分隔或强制断行。获奖按名称、等级、年份排列，同年与跨年保持统一间距；赛项存在时跟随名称，无赛项不留空行，手机按既有布局换行。

## 项目与博客

Projects 一个列表，work／fun 仅元数据。顺序为进行中、完成年月倒序、其他未注明日期。卡片 H2、三行以内简介、同一行的日期／类型／方向；日期 14px，类型与方向 13px。类型为填充矩形，方向为细边框胶囊。标题自然换行，箭头展开时保持卡片几何；整卡一个内链、一个 focus 停靠点。

项目详情标题尾部垂直居中放类型标签，下面显示时间及可选合作单位。资料区按项目概述、项目方向、核心技术排列；概述独占整行、正文大小，手机标签位于值上方。技术紧凑自然换行，正文连续阅读，无目录、阅读时长、独立成果卡片或统一结尾章节；保留真实项目各自背景、动机、复盘等结构。

博客按创建时间倒序，课程章节独立展示。有图才放右侧封面：桌面 160×100px、手机 96×64px；无封面占完整文字区。简介最多两行，封面比例和裁切设置取各篇元数据，不重复增加正文封面。

正文图片居中完整等比，默认不放大小图，限高 `min(60vh, 480px)`；575px 以下 `min(55vh, 360px)`。博客图片保留 HTML 宽高属性的占位作用，不用 `width: auto` 清除未加载图片的宽度；配合 `height: auto` 和 `object-fit: contain` 保持限高后的完整比例。项目原图保持原比例，图前先展示概述。代码块、表格和显示公式局部横向滚动，代码沿用 Nord 明暗配色。

博客阅读容器有 964px 可用宽度时，显示 760px 正文、24px 间距和 180px 右侧目录，否则采用正文内默认收起的原生目录。目录初始顶部与 sticky 偏移相同，底部预留 80px 给回顶控件，短视口只滚动目录。目录翻译不改正文锚点；回顶图标居中，保留悬停反馈和最小键盘支持。

论文保持 APA 参考文献式文字、左图右文和状态标签。原图完整显示不反色；桌面图片区占 40%、最大 400px，窄屏文字在上、图居中。保留当前 JCR／IF、作者前三和状态规则，后续真实原文链接／摘要按 BibTeX 添加。

## 几何与动效

- 根元素保留经典滚动条空间；底部阅读留白在 `.about-content` 内，避免长短页面及页尾移动侧栏。
- 顶部预留桌面 60px、窄屏 52px，优先于进度条运行时 padding。侧栏 sticky 顶部与初始位置相同。
- 导航采用 200ms 原生正文 crossfade，侧栏与导航保持静止；不插值位置／尺寸，不再叠加入场透明动画。
- 原生过渡保留旧视图直到可见头像和封面解码，最多等待 800ms，错误或跳过时清理；预加载头像和前两张博客封面，其余 lazy。首次加载、刷新和同页锚点立即显示。
- 主题切换使用 240ms 全视口渐变，无滑动／裁切／缩放；切换后恢复捕获名称，快速点击取最后选择，保留首屏同步初始化。
- 反馈 160ms、展开 240ms；减少动态效果时关闭相关动画，不支持原生过渡的浏览器沿用正常链接。
- 返回列表跳过目录锚点历史，能确认上一不同页是对应列表时恢复位置，否则使用普通列表链接定位卡片。保持无 JavaScript 的基本导航。

细粒度动效与几何以八份 Chromium 专项为准，Firefox／WebKit 另验证页面及交互兼容性；不支持原生过渡时仍需保持普通导航可用。CAD 的状态、模型范围和交互仅在 [维护说明](VOICE_TERMINAL.md) 维护。
