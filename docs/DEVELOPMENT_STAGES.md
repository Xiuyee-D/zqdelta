## 一、开发环境

Jekyll / al-folio 与 Docker `bin/dev` 为日常入口。英文使用原地址，中文使用 `/zh/`，正式和预览均保留 `/zqdelta`。主机需要 Git、Docker 和 Node/npm；不自动安装系统包。

普通开发不依赖 Python、CAD 或字体重建工具。Firefox／WebKit 的可选容器提供其运行库，与日常 Jekyll 镜像分开；项目内浏览器缓存可以复用。环境初始化、预览和缺少工具时的处理见 [阶段一操作](LOCAL_DEVELOPMENT.md#阶段一环境准备与预览)。

## 二、中文内容

发布范围固定为 About、Projects、Blog、Awards：7 个真实项目、15 篇笔记，含 7 个独立课程章节。主页顺序为简介、动态、论文、教育；侧栏从 about 复用。联系方式、论文数据、教育和项目责任范围均以已确认的源文件为准。

方向、核心技术、时间和研究／工程完成范围已校对。附件保持来源和真实尺寸；CAD 源归档及必要原始输入私有保留。后续修改继续中文优先，具体事实边界见 [内容约定](CONTENT_CONTRACT.md)，不在阶段记录复制各项目全文。

## 三、视觉与交互

Academic Sans、Topaz Nord 配色、共享字号与动效尺度集中维护。Projects 为统一文字列表，Blog 按是否有真实图片显示封面；列表与详情使用一致的阅读列。所有页面共用侧栏和导航工具组，搜索与可见页脚停用。

已保留目录／回顶、列表返回、双语链接、短暂渐变、减少动态效果及无 JavaScript 基础路径。CAD 按需激活，保留静态海报和失败重试。几何、组件及动效规则见 [视觉约定](PROJECT_PRESENTATION.md)，CAD 来源和限位规则见 [维护说明](VOICE_TERMINAL.md)。

## 四、英文同步

英文默认、中文 `/zh/`，共 52 个主要页面，另有一个双语辅助 404。28 组翻译配对包括私有备用论文页；当前项目、栏目及界面已同步。15 篇博客翻译展示元数据与目录，共享 `_includes/blog-content/` 的中文正文，避免重复存储。

同步指纹只在实际英文更新后记录；正文增删章节时同时维护英文目录标签及原锚点。操作见 [阶段四工作流](LOCAL_DEVELOPMENT.md#阶段四英文同步)。

## 五、跨浏览器验收

以项目锁定的 Playwright 版本运行，结果区分引擎和平台，不把 WebKit 写成品牌 Safari。自动化结果在本阶段集中更新；最新截图和机器报告覆盖保存在 `.dev-tools/test-results/`，不扩展成逐次开发档案。

| 环境            | 当前结果 | 依据／范围                                                     |
| --------------- | -------- | -------------------------------------------------------------- |
| Chromium        | 通过     | Ruby 集成和 8 套专项；页面、布局、导航、主题、图片及 CAD       |
| Firefox 146.0.1 | 通过     | Linux 隔离容器；52 页、六组尺寸／主题，阅读、导航及交互 CAD    |
| WebKit 26.0     | 通过     | 同范围检查；375px 另启用移动／触摸模拟，仍属于 Safari 引擎覆盖 |
| Safari 实机     | 通过     | 用户人工确认；具体设备、系统及浏览器版本未记录                 |

正式构建、28 组配对、2,708 处站内资源／锚点、格式、Ruby 集成和覆盖审计已通过。跨浏览器针对独立静态服务上的正式构建产物，Chromium 继续覆盖开发预览。404 的状态码、双语主页链接和不索引规则也纳入验收；窄屏亮色／桌面暗色截图已人工检查。

axe-core 4.14.0 对 53 个页面在 375／1440px、明暗主题下共执行 212 次自动审计，所选 WCAG A／AA 与 best-practice 规则未报告违规；这不替代完整人工无障碍评估。首页保留不可见的语义 H1，实际溢出的阅读区可获得焦点并使用原生方向键滚动，不给普通段落或无需滚动的区域增加 Tab 停靠点。质量审计入口已纳入 `bin/dev audit`，原始报告位于 `.dev-tools/test-results/quality/`，发布验收汇总位于 `release/`；正式网络表现仍需部署后验证。

Academic Sans 已改为静态 Unicode 分片，保留原有 7,807 个字符的度量及 100—900 变量轴，并补齐共享博客正文使用的减号。英文首页／列表请求约 59 KiB 字体，中文首页／项目列表约 175 KiB，较原约 2 MB 降低约 91%；长文使用按当前语料频次分组的正文分片，GB2312 备用字符仍可按需加载。正常构建不运行字体工具，来源、重建和缓存规则见 [字体说明](../assets/fonts/README.md)。

Lighthouse 13.5.0 的当前本地静态服务抽样结果为：中文首页移动模式 86、中文项目列表移动模式 87、英文博客列表桌面模式 100（优化前分别为 74、73、88）；三页的可访问性、最佳实践和 SEO 均为 100。页面 CLS 为 0，TBT 分别为 60／20／0 ms；移动慢网模拟 LCP 约 3.8—3.9 秒，桌面约 0.7 秒。首屏字体瓶颈已缓解，移动端仍有改善空间；这些冷启动模拟结果不代替正式站网络验收。

已用旧完整字体作为对照，检查 7 类页面在 375／768／1440px 的 21 组排版，文字与栏目几何一致。长博客图片保留宽高属性的占位作用，等比限高显示；已补充慢图片加载前后不移动后文的回归，避免快速字体加载暴露原有图片占位缺失。

项目正文和真实资产保持不变；博客只修正引用地址，移除失效超链接时保留工具名称。上游审计保留两项停用功能的非阻断提示：Distill 命名空间、Icons 插件；不为消除提示恢复闲置依赖。Bootstrap 扫描对正文 `cross-modal`／`multi-modal` 的命中属于普通文本，保留原文。
