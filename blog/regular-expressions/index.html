正则表达式基础

字符

表达式 描述
[abc] 字符集。匹配集合中所含的任一字符。
[^abc] 否定字符集。匹配任何不在集合中的字符。
[a-z] 字符范围。匹配指定范围内的任意字符。
. 匹配除换行符以外的任何单个字符。
\ 转义字符。
\w 匹配 Unicode 字母数字及下划线；使用 re.ASCII 时才相当于 [A-Za-z0-9_]。
\W 匹配不属于 \w 的字符，含义受 Unicode／ASCII 模式影响。
\d 匹配 Unicode 十进制数字；re.ASCII 模式下为 [0-9]。
\D 非数字。匹配任何非数字字符。
\s 空白。匹配任何空白字符，包括空格、制表符等。
\S 非空白。匹配任何非空白字符。

分组与选择

表达式 描述
(expression) 分组。匹配括号里的整个表达式。
(?:expression) 非捕获分组。匹配括号里的整个字符串但不获取匹配结果，拿不到分组引用。
\num 对前面所匹配分组的引用。比如(\d)\1可以匹配两个相同的数字，(Code)(Sheep)\1\2则可以匹配CodeSheepCodeSheep。
| 或运算符。并集，可以匹配符号前后的表达式。

边界匹配

表达式 描述
^ 默认匹配字符串开头；re.MULTILINE 模式下也匹配行开头。
$ 匹配字符串结尾或末尾换行之前；多行模式下也匹配行结尾。
\b 匹配单词边界。比如Sheep\b可以匹配CodeSheep末尾的Sheep，不能匹配CodeSheepCode中的Sheep
\B 匹配非单词边界。比如Code\B可以匹配HelloCodeSheep中的Code，不能匹配HelloCode中的Code。

数量表示

表达式 描述
? 匹配前面的表达式 0 个或 1 个。即表示可选项。
+ 匹配前面的表达式至少 1 个。
* 匹配前面的表达式 0 个或多个。
{m} 匹配前面的表达式 m 个。
{m,} 匹配前面的表达式最少 m 个。
{m,n} 匹配前面的表达式最少 m 个，最多 n 个。

预查断言

断言检查当前位置之前或之后的文本是否满足模式，本身不消耗字符。前瞻检查后方文本，后顾检查前方文本；Python re 的后顾模式需满足固定长度要求。

表达式 描述
(?=) 正向预查。比如Code(?=Sheep)能匹配CodeSheep中的Code，但不能匹配CodePig中的Code。
(?!) 正向否定预查。比如Code(?!Sheep)不能匹配CodeSheep中的Code，但能匹配CodePig中的Code。
(?<=) 反向预查。比如(?<=Code)Sheep能匹配CodeSheep中的Sheep，但不能匹配ReadSheep中的Sheep。
(?<!) 反向否定预查。比如(?<!Code)Sheep不能匹配CodeSheep中的Sheep，但能匹配ReadSheep中的Sheep。

匹配标志

表达式 描述
re.IGNORECASE 忽略大小写。
re.MULTILINE 改变 ^ 和 $ 的多行匹配行为。

匹配与替换示例

import re

print(re.fullmatch(r"[A-Za-z]+\d{2}", "Code24") is not None)  # True
print(re.fullmatch(r"[A-Za-z]+\d{2}", "Code2") is not None)   # False
print(re.findall(r"Code(?=Sheep)", "CodeSheep CodePig"))     # ['Code']
print(re.sub(r"\s+", " ", "a   b\tc"))                    # 'a b c'

search() 在字符串内寻找匹配，match() 从开头尝试，fullmatch() 要求完整字符串匹配。findall() 返回所有不重叠匹配的列表，finditer() 返回匹配对象的迭代器。*、+、? 和范围量词默认采用贪婪匹配，后加 ? 可改为非贪婪形式，如 .*?。完整规则见 Python re 文档。
