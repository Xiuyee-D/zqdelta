多型号设备统一测控软件

工程
  • 项目时间：2024.08—2025.04
项目概述
面向多型号设备的性能测试，负责桌面软件总体框架与多协议通信适配，参与团队模块集成及交付，支持 3 类设备的测试管理、结果可视化与报告生成。
项目方向
  • 软件工程
  • 工业通信
核心技术
  • PySide2
  • Qt Designer
  • GitLab

项目背景

该横向项目面向多型号设备的性能测试、数据采集与结果判定，将设备控制、测试流程、结果可视化与报告生成整合到统一桌面平台。各型号的通信方式、指令和数据格式不同，功能模块又由团队成员并行开发，需要兼顾设备接入、界面一致性与阶段集成的稳定性。

主要工作

桌面软件架构与界面规范

负责基于 PySide2 的桌面软件总体框架设计与搭建，按界面交互、测试流程、设备通信和数据处理划分模块职责，明确团队开发边界。建立共用布局、操作流程与状态反馈规范，使并行开发的模块能够沿用一致的交互方式和结果展示形式。

统一设备接口与多协议通信

设计面向业务操作的统一设备接口，将连接管理、指令收发及响应解析封装在设备适配层，完成 TCP、UDP、Modbus TCP 及 RS-422 等通信方式的适配。新增设备时封装该型号的控制指令和数据解析模块，上层测试流程与界面通过约定接口调用设备功能，不直接处理报文及协议差异。

跨模块集成与交付协调

参与功能拆分及跨模块接口协调，通过 GitLab 功能分支与 Merge Request（MR） 集成团队成员的开发成果。在短周期集成中识别重复控制逻辑、解析实现与组件样式偏差，协商合并共用模块并校准界面，及时处理模块职责和调用接口的分歧。

后期承担项目进度协调与系统联调安排，交付前驻场联调，贯通实际设备接入、数据采集、结果展示与报告生成流程，整理测试版本和交付文档。完成支持 3 类设备统一测试管理的软件交付及用户使用手册。
