# ZD 主标识

以 Ziqian Deng 的首字母组成错位交叠的手写字标：Z 位于左上、D 位于右下，Z 的收笔横跨 D 的左侧，呈现前后关系。字形使用自行绘制的贝塞尔轮廓，以弧形起收笔、自然倾斜及粗细变化保留书写感，并兼顾 16px 下的辨识度。不依赖字体或外部资源。

圆形底使用 Nord 深灰 `#2E3440`，Z 使用霜白 `#ECEFF4`，D 使用暖金 `#EBCB8B`；明暗主题、中英文共用同一标识。字形整体缩至原版的 94%，并稍向上调整，使笔画与圆边保留均衡留白。

| 文件                   | 用途                                        |
| ---------------------- | ------------------------------------------- |
| `monogram.svg`         | 可编辑的 64×64 矢量母版、现代浏览器标签图标 |
| `favicon.ico`          | 16／32／48px 浏览器兼容图标                 |
| `favicon-48.png`       | 48px PNG 图标                               |
| `apple-touch-icon.png` | 180px Apple 主屏幕收藏图标                  |

`_config.yml` 声明文件路径，`_includes/head.liquid` 输出保留 `/zqdelta` 前缀及内容版本参数的图标链接。SVG、PNG 和 ICO 在圆形以外保持透明。Apple 图标在 180px 的不透明霜白底板上居中放置 160px 圆形标识，由系统处理外框。页面侧栏继续使用个人头像。

修改母版后，使用现有 Docker 环境重新导出并检查 16px、32px 的辨识度：

```bash
./bin/dev bundle exec ruby bin/build-brand-icons.rb
```

导出脚本读取本标识的 `rect`／`circle`／`path` 及纯色填充，使用现有 ImageMagick 绘图引擎生成位图，无需额外的 SVG 转换器。普通 Jekyll 构建直接使用已保存的图标，不执行重建。增加其他 SVG 图元时需同步调整导出脚本。
